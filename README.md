FitnessKing

“Fitness King” is a combined website and application designed to help users with fitness and healthy weight gain/weight loss. It helps users with fitness through showing different exercises for different muscle groups and helps the users with weight loss / gain through abilities to calculate the require calories for doing both. 

Utilized a waterfall methodology to create the website first to then base the application on its design for better choesion between platforms.

The system uses a combination of MySQL (Website) and Firebase (Application) for user authentication and data storage such as biometrics (height, weight).

The website features dynamic page generation, meaning that content is created in real time based on data retrieved from the database.

The user’s fitness data is used to calculate different caloric goals depending on options chosen by the user.

Authentication on the website includes input validation to ensure that user data is correctly formatted before being checked against the MySQL database.

Testing revealed ethics problems when test users were making accounts, the cause was entering their real biometric data which was then changed to ensure they could make an account without that data and would be able to enter later if they wished.
